# Nevera Docs

Welcome to the documentation for Nevera FiveM resources.

## Who we are

Nevera builds **Hard RolePlay** scripts for FiveM — systems designed to work the way the real world does, not a simplified arcade version of it. Real court procedure, real-world weather tied to real cities, real consequences for real actions. If it wouldn't make sense in real life, it doesn't ship.
